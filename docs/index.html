Reflectodoro

A Pomodoro app whose real point is forcing a short self-reflection at the end of every break — "what did I do?" — enforced by a hard-to-dismiss overlay.

Download for Windows (.exe) Download for macOS (.dmg) Download for Linux (.AppImage) View source on GitHub

Windows may show a SmartScreen "unknown publisher" warning on first run — choose More info → Run anyway.
On macOS, the app isn't notarized yet, so Gatekeeper will block it the first time — right-click the app and choose Open, or run xattr -cr /Applications/Reflectodoro.app in Terminal.
On Linux, make the AppImage executable first (chmod +x Reflectodoro*.AppImage); some distros also need libfuse2 installed for it to run.

Wall-clock breaks ⏲

Work and break slots are pinned to fixed clock boundaries.

No free pass 🔒

The break overlay can't be dismissed directly — you have to write what you did and wait for break time to be over.

Emergency exit ⚡

Type a random on-screen string to end the break early — still requires the reflection either way.

Wellness check 🌱

Wellness check at the end of break to track break items i.e. did short exercise, relaxed eyes, drank water.

Fully local and private 💻

All of your data is stored on your device. No cloud data transfer.

Auto-pause Media ⏸️

Auto-pause music/movies during breaktime, so you do not get spoilers 😜 when you get back.

Cross-platform support 📱

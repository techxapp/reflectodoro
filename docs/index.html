Reflectodoro

A Pomodoro app whose real point is forcing a short self-reflection at the end of every break — "what did I do?" — enforced by a hard-to-dismiss overlay.

Download for Windows (.msi) View source on GitHub

Windows may show a SmartScreen "unknown publisher" warning on first run — choose More info → Run anyway. The app isn't code-signed yet.

Wall-clock breaks

Work and break slots are pinned to fixed clock boundaries, not a rolling timer that drifts.

No free pass

The break overlay can't be dismissed by waiting it out — you always have to write what you did.

breakit challenge

Type a random on-screen string to end the break early — still requires the reflection either way.

Fully local

Everything is stored on-device in SQLite. No account, no server, no sync.
